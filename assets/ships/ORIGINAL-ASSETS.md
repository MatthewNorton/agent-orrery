# Original ship assets

## Aster Kite

`aur-aster-kite.glb` is an original low-poly split-wing courier/interceptor
created for Agent Universe Lite. Its geometry is generated deterministically
by `scripts/generate-original-ship.mjs`; it is not derived from the bundled
Kenney or Quaternius models.

The embedded albedo uses `textures/aur-aster-kite-albedo.jpg`, generated with
OpenAI ImageGen as flat spaceship hull material artwork and reduced to a
512-by-512 JPEG for runtime use. Provider tint is applied to the separate
`accent_energy` material, leaving the hull texture intact.

Design and generated asset: CC0-1.0. The source texture prompt is recorded in
this file and can be replaced without changing the model generator.

> Create a square, tile-friendly flat albedo texture for an original low-poly
> spaceship: interlocking graphite and deep-navy armor plates, sparse cyan
> energy channels, muted violet and burnt-orange hardware accents, subtle
> panel-seam occlusion and restrained edge wear. No environment, ship
> silhouette, cockpit, directional lighting, perspective, text, logos, or
> watermark. Keep the design readable when reduced to 512 pixels.

Regenerate the GLB from the repository root:

```powershell
npm run ships:generate
```

## Vanta Seraph

`aur-vanta-seraph.glb` is the flagship quality benchmark for the original
fleet: an elite command interceptor with layered bifurcated wings, twin
physical gravitic ring drives, a raised dorsal spine, smoked canopy, triple
thrusters, structural rails, and close-up mechanical greebles. The model uses
seven distinct PBR materials and embeds both a 1024-by-1024 albedo atlas and an
aligned tangent-space normal map.

The generator produces several thousand triangles while remaining below the
two-megabyte asset cap and the scene triangle budget. It faces +Z with +Y up.
Design, generated geometry, and production textures: CC0-1.0.

Texture generation brief:

> Create a premium flat PBR albedo atlas of graphite titanium, midnight-blue
> ceramic armor, gunmetal mechanisms, restrained ivory rails, sparse cyan and
> ultraviolet energy traces, and tiny amber service details. Include fine
> panel gaps, vents, fasteners, bevel variation, and restrained wear. No
> perspective, baked lighting, logos, readable symbols, text, or watermark.

The normal map was generated as an aligned material transformation of that
atlas, preserving its panel layout while encoding restrained seam, bevel,
fastener, and vent relief around neutral tangent-space blue.

Regenerate only the flagship:

```powershell
npm run ships:generate:flagship
```

## Shared original fleet

The active Claude and Codex fleets share six original hull designs. Hull shape
represents visual class and silhouette; provider identity is applied at runtime
through the complete material set. Every Claude hull uses the same Claude
purple, and every Codex hull uses the same Codex cyan. Agent IDs no longer
select slightly different colors within a provider.

The active fleet contains two hulls per deterministic size role:

- Small: Halcyon Dart and Kiteglass Runner
- Medium: Meridian Talon and Cinder Relay
- Large: Vanta Seraph and Crown Warden

The five non-flagship models are generated by
`scripts/generate-fleet-ships.mjs`. They embed a shared 1024-by-1024 neutral
albedo and aligned tangent-space normal map. The neutral graphite, gunmetal,
silver, and pale-mask palette is deliberately free of provider colors so the
runtime tint remains clean and unmistakable.

Signal-provider entries and `kind: "drone"` entries do not select a GLB. They
render as billboarded transmission markers instead of physical spacecraft.

Neutral fleet texture generation brief:

> Create a premium, square, tile-friendly PBR spacecraft material atlas with
> interlocking graphite armor, charcoal ceramic, dark gunmetal, cool silver
> structure, pale mask panels, vents, fasteners, access plates, energy-channel
> masks, restrained wear, and fine machined detail. Keep it color-neutral for
> runtime tinting. No ship silhouette, perspective, baked lighting, readable
> text, logos, watermark, or provider-specific colors.

The normal map was generated from the exact albedo layout, preserving its
panel registration while encoding shallow seams, bevels, vents, fasteners,
and subtle material relief around tangent-space neutral blue.

Regenerate the shared fleet:

```powershell
npm run ships:generate:fleet
```

All original geometry and generated production textures are released under
CC0-1.0.
