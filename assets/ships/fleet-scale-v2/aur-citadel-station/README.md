# AUR Citadel Station

Original Blender-ready modular orbital station from the AUR Fleet Scale v2 family.

- Dimensions: 5000.0 m × 5000.0 m × 2600.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-citadel-station.blend`
- Runtime: `aur-citadel-station.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-citadel-station.fbx`
- Reference: `references/aur-citadel-station-turnaround.png`
- Rebuild: run `build_aur-citadel-station.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
