# AUR Wayfarer Shuttle

Original Blender-ready crew and cargo shuttle from the AUR Fleet Scale v2 family.

- Dimensions: 24.0 m × 35.0 m × 8.5 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-wayfarer-shuttle.blend`
- Runtime: `aur-wayfarer-shuttle.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-wayfarer-shuttle.fbx`
- Reference: `references/aur-wayfarer-shuttle-turnaround.png`
- Rebuild: run `build_aur-wayfarer-shuttle.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
