# AUR Vigil Frigate

Original Blender-ready long-keel escort frigate from the AUR Fleet Scale v2 family.

- Dimensions: 92.0 m × 220.0 m × 38.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-vigil-frigate.blend`
- Runtime: `aur-vigil-frigate.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-vigil-frigate.fbx`
- Reference: `references/aur-vigil-frigate-turnaround.png`
- Rebuild: run `build_aur-vigil-frigate.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
