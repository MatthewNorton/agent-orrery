# AUR Ark Carrier

Original Blender-ready trident fleet carrier from the AUR Fleet Scale v2 family.

- Dimensions: 780.0 m × 1600.0 m × 240.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-ark-carrier.blend`
- Runtime: `aur-ark-carrier.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-ark-carrier.fbx`
- Reference: `references/aur-ark-carrier-turnaround.png`
- Rebuild: run `build_aur-ark-carrier.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
