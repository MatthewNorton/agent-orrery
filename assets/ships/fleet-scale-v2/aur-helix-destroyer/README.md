# AUR Helix Destroyer

Original Blender-ready spinal-rail heavy destroyer from the AUR Fleet Scale v2 family.

- Dimensions: 180.0 m × 450.0 m × 72.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-helix-destroyer.blend`
- Runtime: `aur-helix-destroyer.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-helix-destroyer.fbx`
- Reference: `references/aur-helix-destroyer-turnaround.png`
- Rebuild: run `build_aur-helix-destroyer.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
