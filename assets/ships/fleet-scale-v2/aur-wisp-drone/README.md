# AUR Wisp Drone

Original Blender-ready autonomous reconnaissance drone from the AUR Fleet Scale v2 family.

- Dimensions: 2.4 m × 1.8 m × 0.72 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-wisp-drone.blend`
- Runtime: `aur-wisp-drone.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-wisp-drone.fbx`
- Reference: `references/aur-wisp-drone-turnaround.png`
- Rebuild: run `build_aur-wisp-drone.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
