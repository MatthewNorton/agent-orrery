# AUR Lance Interceptor

Original Blender-ready single-seat interceptor from the AUR Fleet Scale v2 family.

- Dimensions: 9.0 m × 14.0 m × 3.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-lance-interceptor.blend`
- Runtime: `aur-lance-interceptor.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-lance-interceptor.fbx`
- Reference: `references/aur-lance-interceptor-turnaround.png`
- Rebuild: run `build_aur-lance-interceptor.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
