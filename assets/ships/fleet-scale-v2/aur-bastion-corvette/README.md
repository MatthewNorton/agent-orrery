# AUR Bastion Corvette

Original Blender-ready armored patrol corvette from the AUR Fleet Scale v2 family.

- Dimensions: 46.0 m × 90.0 m × 18.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-bastion-corvette.blend`
- Runtime: `aur-bastion-corvette.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-bastion-corvette.fbx`
- Reference: `references/aur-bastion-corvette-turnaround.png`
- Rebuild: run `build_aur-bastion-corvette.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
