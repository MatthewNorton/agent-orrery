# AUR Atlas Cruiser

Original Blender-ready fleet command cruiser from the AUR Fleet Scale v2 family.

- Dimensions: 420.0 m × 850.0 m × 160.0 m (X/Y/Z)
- Forward: +Y; up: +Z
- Master: `aur-atlas-cruiser.blend`
- Runtime: `aur-atlas-cruiser.glb` (Babylon.js / standards-compliant glTF)
- Interchange: `aur-atlas-cruiser.fbx`
- Reference: `references/aur-atlas-cruiser-turnaround.png`
- Rebuild: run `build_aur-atlas-cruiser.py` through Blender in background mode
- License: CC0-1.0

The GLB uses image-backed base color, normal, and metallic-roughness inputs. No floor, display base, backdrop, lights, or camera are exported.
